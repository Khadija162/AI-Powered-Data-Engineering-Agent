# Open research data

Iris data (150 rows) originates from UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/53/iris; DOI https://doi.org/10.24432/C56C76; CC BY 4.0. This CSV is a normalized copy of the scikit-learn public upstream Iris data file (first metadata line removed, explicit feature names added): https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/data/iris.csv . No customer or sensitive data is included.
